# Recorded experiment artifacts

These are selected outputs from the original Windows laptop experiments, copied
byte-for-byte. Original paths and hashes are provenance, not portable input paths.
Sources remain at the repository root. Runtime outputs go to ignored `runs/`,
`results/` and `data/` folders; `reports/` is the published snapshot.

Weights, raw datasets, per-posting model outputs and API ledgers are not included.
These records let readers inspect results, but do not by themselves reproduce
training or inference. See the root README for requirements and limitations.
